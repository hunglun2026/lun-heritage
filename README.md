# 古蹟探險家

https://heritage.hunglun.com

用文化部文化資產局的開放資料（[政府資料開放平臺「文資局古蹟」](https://data.gov.tw/dataset/6246)，政府資料開放授權條款第1版），認識臺灣 1,065 處古蹟。幼兒園、國小、國中、高中四種程度，不用登入。

- 古蹟圖鑑：搜尋、篩選、白話介紹或原文、比一比
- 我家附近的古蹟：地圖與裝置定位（位置只在裝置上計算）
- 看建築認類型、時代排排看、猜猜我是誰、翻牌配對
- 探險護照、老師專區（學習單、搶答計分板）

分級介紹由 AI 依原文改寫，只能用原文寫到的事實，再用程式查核數字、年代、時代用詞與簡體字（改寫在 `data/ai/`）。發現錯誤請按網站頁尾「回報內容錯誤」。

技術：Cloudflare Workers 靜態資源＋一支 Worker（每月比對資料更新、回報錯誤轉通知），沒有資料庫。資料與前端骨架由 super-opendata-edu 工具產生。
